# MarketSense-Stock-Trend-Prediction

## 📈 Project Overview
A machine learning-based stock trend prediction system that analyzes historical stock data to forecast future price movements. This project implements various regression models with comprehensive data preprocessing and feature engineering techniques.

## 🎯 Key Features
- Fetches real-time stock data using Yahoo Finance API
- Comprehensive data preprocessing and scaling
- LSTM neural networks for time series prediction
- Multiple regression model implementations
- Automated feature selection and engineering
- Robust error handling with retry logic
- Reproducible prediction pipeline

## 📊 Technical Highlights
- **Data Processing**: Built an ML model for stock trend prediction using **10,000+ historical records** with advanced preprocessing and feature selection techniques
- **Model Optimization**: Evaluated multiple regression models in Python, achieving **~15–20% MSE reduction** while carefully analyzing overfitting/underfitting scenarios
- **Production Ready**: Deployed a reproducible prediction pipeline ensuring **consistent results on unseen data**
- **Deep Learning**: Implemented LSTM networks for capturing temporal dependencies in stock price patterns

## 🛠️ Technologies Used
- Python 3.7+
- TensorFlow/Keras (LSTM)
- scikit-learn (Regression models)
- yFinance (Data collection)
- Pandas & NumPy (Data manipulation)
- Matplotlib (Visualization)
- SciPy (Optimization)
